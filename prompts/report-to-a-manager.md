# Report to a manager or client

A one-page summary of what search did for the business, and a memo for one decision. Skill: `seo-reporting`, section "The executive summary".

## Workflow: Executive summary

### Step 1: The scorecard

```text
For my site [site], for [the last 28 days, or the quarter], compared with the period before:

1. search_console: clicks and impressions.
2. analytics_pages, if Analytics is connected: visits from search.
3. project_overview and list_keywords: tracked keywords in the top 3 and the top 10.
4. competitor_traffic, if rivals are saved: visits from search for my site and each rival, marked as estimates. Use its monthly series for the period before.

Return one table: Metric | This period | Period before | Change | Source | Window.
Four to six rows. Leave out any metric without a source and write "not reported" instead of a guess.
```

### Step 2: The summary

```text
If the scorecard from the previous step is in this conversation, use it. If not, run that step first. Use my change log if it is in this conversation.

Write one page for a manager who does not know SEO, in this order:
1. Headline: one sentence on what search did for the business.
2. The scorecard.
3. What worked: up to three changes whose check date has passed, with the result.
4. What did not: up to three, with the cause if known.
5. Risks: rivals closing in on money keywords, pages sliding, open technical problems.
6. Decisions needed: each with options and what you recommend.
7. Next period: three to five priorities.

Plain words. Explain any term the first time. Do not credit a change for a rise that started before it.
```

## Workflow: Decision memo

### Step 1: One decision

```text
I need to decide: [the decision, for example "redesign the shop" or "write 10 new guides or fix the existing pages first"].

Use the tables already in this conversation. If something is missing, run the read-only tools that answer it (page_updates, site_pages, search_console, keyword_gap) and say which you ran.

Write a memo of at most half a page:
- The decision in one sentence
- Two or three options
- For each option: the evidence (number and source), the effort, and the risk
- What you recommend, and the one number to check in 30 days to see if it was right

Do not promise outcomes.
```
